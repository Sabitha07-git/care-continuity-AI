# Care Continuity AI

An AI-powered healthcare continuity platform that consolidates fragmented medical records into a longitudinal patient history.

## Problem

Healthcare information is often fragmented across hospitals, diagnostic centers, prescriptions, and previous consultations. Reviewing multiple records manually can be time-consuming and may cause important changes, missing information, or conflicting information to be overlooked.

## Proposed Solution

Care Continuity AI:

- Consolidates patient records
- Builds a longitudinal timeline
- Identifies trends in medical information
- Flags potential conflicts and information gaps
- Provides source-grounded answers using RAG

## Tech Stack

- Python
- Streamlit
- PostgreSQL
- ChromaDB
- LLM API
- LangChain
- Plotly

> **Note:** This is a hackathon prototype for demonstration purposes and is not intended for diagnosis or clinical decision-making.
